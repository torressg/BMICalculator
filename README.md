# BMI Calculator (Dart CLI)

First challenge of the Santander Bootcamp 2023: a Body Mass Index calculator that runs in the terminal, written in plain Dart.

The user types name, weight and height, and the program prints the BMI and its classification. The data is modeled with a `Person` class.

## Running

```bash
cd bmi_calculator
dart pub get
dart run
```

Later I built a full Flutter version with history and SQLite: [calculadora_de_IMC](https://github.com/torressg/calculadora_de_IMC).
